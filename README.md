# Elevator Inspector: BLT-NS (2013)

Игра-инструмент / симулятор **настоящего BLT-NS из подъезда владельца**. Виртуальный двойник,
с которым можно делать всё то, что в реале нельзя: открывать двери шахты треугольником,
заходить в шкаф управления, кататься в ревизии на крыше кабины и смотреть, как срабатывает
защита. Без штрафов.

**Принцип вида:** никаких разрезов и «рентгена». Ты человек-механик и видишь только то место,
где физически находишься: этажная площадка, кабина, крыша кабины, шкаф управления, приямок
или лестница/крыша здания. Зато движение лифта честное: позиция в метрах, разгон/торможение,
точная остановка, тайминги дверей, цепь безопасности и ревизия с удержанием кнопок.

## Паспорт реального лифта (внесён в игру)

- «Лифт без машинного помещения», тип **BLT-NS**, Shenyang Brilliant
- Выпуск **BLT13K/1055**, дата **03.2013**
- **1000 кг**, **1,0 м/с**, обслуживает этажи **1–10**
- Лестница продолжается до **12-го этажа**, там выход на крышу здания
- Шкаф управления **LCM3 № DHT-120363T (16#)** — 10-й этаж, справа от дверей и вызовов
- Панель приказа: сверху табло с анимированной стрелкой, жёлтая кнопка диспетчера,
  внизу сервисная панель на ключе — *Лифтёр, Специальная загрузка, Удержание дверей,
  Вентилятор, Запасной*
- Голосовых объявлений нет
- Характер: стучит при подъёме с 1-го этажа; на 10-м громко стучит и выравнивается ~8 секунд

📋 **Идеи, системы и дорожная карта:** [docs/DESIGN.md](docs/DESIGN.md)

## Запуск

Чистый веб без сборки:
```bash
python3 -m http.server 8000 --bind 0.0.0.0
# открыть http://localhost:8000
```
Тесты модели лифта:
```bash
node tests/sim.test.mjs
```

## Структура
- `src/config.js` — параметры реального лифта одним файлом (помечено, что подтверждено
  владельцем, а что ещё заглушка: высота этажа и тайминги дверей)
- `src/sim.js` — модель: физика движения, двери, вызовы/приказы, цепь безопасности,
  режимы станции и сервисной панели, долгое выравнивание на 10-м
- `src/main.js` — вид глазами механика (Canvas), панели, звук и характерные стуки, задания
- `tests/sim.test.mjs` — тесты модели, включая стук с 1-го, выравнивание на 10-м
  и все 5 переключателей сервисной панели

Статус: **v0.2 играбелен с настоящими параметрами лифта владельца**.
