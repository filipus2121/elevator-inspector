# Elevator Inspector: BLT-NS (2013)

Игра-инструмент / симулятор пассажирского лифта **BLT-NS 2013 года** (Shenyang Brilliant),
который стоит в реальном подъезде. Виртуальный двойник настоящего лифта, с которым можно
делать всё то, что в реале нельзя: открывать двери шахты треугольником, заходить в шкаф
управления, кататься в ревизии на крыше кабины и смотреть, как срабатывает защита. Без штрафов.

**Принцип вида:** никаких разрезов и «рентгена». Ты человек-механик и видишь только то место,
где физически находишься: этажная площадка, кабина, крыша кабины, шкаф управления, приямок.
Зато движение лифта честное: позиция в метрах, разгон/торможение, точная остановка,
тайминги дверей, цепь безопасности и режим ревизии с удержанием кнопок.

📋 **Идеи, системы и дорожная карта:** [docs/DESIGN.md](docs/DESIGN.md)

## Запуск

Чистый веб без сборки:
```bash
python3 -m http.server 8000 --bind 0.0.0.0
# открыть http://localhost:8000
```
Тесты модели лифта:
```bash
node tests/sim.test.mjs
```

## Структура
- `src/config.js` — **все параметры реального лифта одним файлом** (сейчас временные
  заглушки: 9 этажей, 630 кг, 1.0 м/с; заменит владелец настоящими данными своего BLT-NS)
- `src/sim.js` — модель: физика движения, двери, вызовы/приказы, цепь безопасности,
  режимы станции (нормальная / ревизия / сервис / без питания)
- `src/main.js` — вид глазами механика (Canvas), панели управления, звук, задания
- `tests/sim.test.mjs` — тесты модели (поездка и остановка ±5 мм, стоп от треугольника,
  ревизия с лимитом скорости, потеря питания)

Статус: **v0.1 играбелен** — коридор «площадка → кабина → шкаф управления →
треугольник → крыша в ревизии → приямок» работает. Следующий шаг — настоящие параметры
лифта владельца (раздел 8 в дизайн-документе) и его «характер»: звуки, глюки, индикаторы.
